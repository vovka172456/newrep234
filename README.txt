ПРОЕКТ «ПОИСК КНИГ»

Как запустить:
1. Распакуйте архив.
2. Откройте папку BookSearch в Visual Studio Code.
3. Откройте терминал (Terminal -> New Terminal).
4. Выполните команду: npm install
5. Выполните команду: npm run dev
6. Откройте адрес, который появится в терминале (обычно http://localhost:5173).

Для работы поиска нужен интернет. Приложение использует бесплатный Open Library API.
